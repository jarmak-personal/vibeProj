# Transcendental experiments

This directory separates research history from vibeProj's maintained developer
contract.

- [`qualification.md`](qualification.md) records what was measured, accepted,
  or rejected on named hardware.
- [`roadmap.md`](roadmap.md) records what remains worth exploring.
- [`docs/dev/transcendentals.md`](../../docs/dev/transcendentals.md) is the
  authoritative current inventory and production qualification contract.

Experimental results do not enable a strategy. Only the central registry and
its coverage tests define production behavior.
